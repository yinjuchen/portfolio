# Tiffany Chen — Portfolio

Personal portfolio site for Tiffany Chen, a text-based Customer Support
Specialist (7+ years) transitioning into Technical Support, AI QA, and AI
Support Operations. The site walks through self-initiated case studies
(support ticket triage, AI response review, AI-assisted support workflow
design) alongside smaller technical learning projects.

**Live site:** [yinjuchen.netlify.app](https://yinjuchen.netlify.app/)
**Resume:** [`public/Resume_ChenYinJu.pdf`](./public/Resume_ChenYinJu.pdf)

## Tech stack

- React 18 + React Router v6 (bootstrapped with Create React App)
- SCSS per component
- Deployed on Netlify (SPA routing handled via `public/_redirects`)

## Structure

- `/` — home
- `/about` — background, skills, and roles I'm open to
- `/projects` — case studies and technical learning projects
  - `/projects/support-ticket-analysis`
  - `/projects/ai-support-response-review`
  - `/projects/ai-assisted-support-workflow`

## Development

```bash
npm install     # install dependencies
npm start       # run the dev server at http://localhost:3000
npm test        # run the test suite (watch mode)
npm run build   # production build, output to /build
```
